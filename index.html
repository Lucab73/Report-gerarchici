1. Un file o due? — La scelta iniziale

All'avvio l'app chiede come vuoi lavorare:

  • 📄 Un file CSV — il flusso classico: carichi un singolo file e costruisci il report. Vai direttamente al punto 2.
  • 📄📄 Due file CSV — carica due file separati, li unisci su una o più colonne comuni e costruisci il report usando campi da entrambi. Segui i punti 2, 3 e 4 prima di passare alla costruzione.

2. Importazione e Pulizia Dati

Lo stesso procedimento si ripete per ogni file caricato (File 1 e, se scegli due file, File 2).

  • Trascina il file .CSV nell'area apposita oppure clicca per selezionarlo dal computer.
  • Nella tabella superiore seleziona le righe che contengono le intestazioni (nomi colonna) spuntando le checkbox. Puoi selezionarne più di una se le intestazioni sono su più livelli — verranno unite automaticamente in un unico nome.
  • Nella tabella inferiore deseleziona eventuali righe finali inutili (totali precalcolati, note, righe vuote di coda).
  • Clicca Conferma Dati e verifica nel box riepilogativo il numero di righe e colonne rilevate. Le prime 3 righe vengono mostrate come anteprima.
  • Se lavori con un solo file, il bottone Procedi ➔ ti porta direttamente alla costruzione del report. Se lavori con due file, il bottone rivela la sezione per caricare il File 2.

3. Normalizzazione Testo 🧹

Prima di proseguire puoi pulire i valori del CSV in memoria cliccando 🧹 Normalizza Testo nel box di conferma. Quando lavori con due file il bottone è disponibile separatamente per ciascuno. Il pannello mostra una riga per ogni colonna con il tipo rilevato automaticamente (Testo, Numerico o Misto) e un'anteprima in tempo reale della trasformazione.

Operazioni disponibili:

  • ✂️ Trim Rimuove spazi e tabulazioni prima e dopo il testo. Es. " Mario Rossi " → "Mario Rossi".
  • ⎵ Spazi doppi Riduce sequenze di spazi interni a uno solo. Es. "Mario   Rossi" → "Mario Rossi".
  • 🔠 Maiuscolo / 🔡 Minuscolo / 🔤 Prima Lettera Conversioni di capitalizzazione, mutuamente esclusive.
  • ✔ Sì/No Standardizza valori booleani: si, yes, 1, true, x → Sì; no, 0, false → No.
  • 🗑 Rimuovi punct Elimina punteggiatura (. , ; : ! ? " ' ( ) [ ] { } - _ / \). Utile per uniformare codici con separatori inconsistenti.

La barra "Applica a tutte" in cima spunta un'operazione su tutte le colonne in un click. Clicca Applica Normalizzazione per confermare — un messaggio mostra quanti valori sono stati modificati.

⚠️ Consiglio quando usi due file: se la colonna comune (usata per unire i file) ha valori con formati diversi — es. "1463" in un file e " 1463 " con spazi nell'altro — il join non troverà corrispondenze. Usa Trim su entrambi i file prima di configurare l'unione.

4. Configurazione Unione (JOIN) — Solo con due file

Dopo aver confermato entrambi i file, clicca Configura Unione ➔. Questa sezione permette di definire come i due file vengono collegati tra loro.

4a. Colonne di join — chiave semplice o composita

L'app analizza automaticamente le intestazioni dei due file e suggerisce le colonne con nome uguale o simile come candidati per il join. Puoi modificarle liberamente.

  • Ogni riga nella sezione join rappresenta una coppia: colonna del File 1 = colonna del File 2.
  • Puoi usare più coppie contemporaneamente (chiave composita): il join avviene sulla condizione che tutte le coppie corrispondano. I due campi restano separati nel report e sono selezionabili indipendentemente.
  • Aggiungi coppie con il bottone ＋ Aggiungi colonna di join; rimuovile con il tasto ✕ a fianco.

Esempio: se File 1 ha CDC e Impegno e File 2 ha le stesse colonne, impostare due coppie (CDC=CDC e Impegno=Impegno) garantisce che due impegni con lo stesso codice ma centri di costo diversi non vengano mai mescolati.

4b. Cardinalità — cosa significa e perché conta

La cardinalità descrive il rapporto numerico tra le righe dei due file rispetto alla chiave scelta. L'app la calcola in tempo reale e la mostra con un badge colorato.

✅ 1:1 Perfetto. Ogni riga del File 1 ha al massimo una corrispondenza nel File 2 e viceversa. Il risultato è pulito e prevedibile — il numero di righe non cambia rispetto al File 1. Esempio tipico: due anagrafiche con lo stesso codice univoco.
🟡 1:N Normale e spesso voluto. Ogni riga del File 1 corrisponde a più righe del File 2. Il risultato ha più righe del File 1 originale: ogni "master" viene ripetuto tante volte quante sono le sue righe di dettaglio. Esempio tipico: un cliente (F1) con più ordini (F2), un impegno (F1) con più atti di liquidazione (F2). Questo è corretto se vuoi vedere il dettaglio di ogni collegamento.
🔴 N:M Attenzione — quasi sempre un problema. Sia il File 1 che il File 2 hanno valori ripetuti per le colonne di join scelte. Il join produce una combinazione moltiplicativa: ogni riga di F1 viene abbinata a tutte le righe corrispondenti di F2, e viceversa. Il risultato può avere molte più righe del previsto e, soprattutto, i valori numerici risultano duplicati e gonfiati.
Esempio concreto di N:M problematico: File 1 ha due righe per l'impegno 3260001 (due voci di capitolo: 10.000 e 20.000). File 2 ha tre liquidazioni per lo stesso impegno (DD/201 5.000, DD/202 3.000, DD/203 2.000). Il join su impegno produce 2×3=6 righe: ogni liquidazione compare due volte, e se fai la somma delle liquidazioni ottieni 20.000 invece di 10.000. I dati appaiono corretti ma sono gonfiati del doppio.
Quando N:M può essere accettabile: se hai bisogno di vedere tutte le combinazioni tra le righe dei due file senza aggregare valori numerici — ad esempio un report puramente testuale che elenca tutte le coppie (voce di costo × determina) senza fare somme — il N:M è inoffensivo. In questo caso spunta la casella di conferma che appare nell'avviso arancione e procedi.
Come ridurre o eliminare un N:M: aggiungi altre colonne alla chiave composita. Se oltre a CDC e Impegno esiste un'altra colonna che distingue le righe (es. Voce di Costo, Anno, Capitolo), aggiungila come terza coppia di join — spesso la cardinalità scende a 1:N o 1:1.

4c. Tipo di JOIN

  • LEFT JOIN (predefinito): tutte le righe del File 1 compaiono nel risultato, anche se non hanno corrispondenza nel File 2. I campi di F2 risulteranno vuoti per quelle righe. Usa questa opzione quando vuoi vedere anche i record "orfani" del File 1.
  • INNER JOIN: solo le righe che hanno corrispondenza in entrambi i file. Le righe di F1 senza match vengono scartate. Usa questa opzione quando ti interessano solo i dati completi e non vuoi righe con campi vuoti.

4d. Conflitti di nome colonna

Se entrambi i file contengono una colonna con lo stesso nome (diversa da quelle usate come chiave di join), l'app la rinomina automaticamente aggiungendo il nome del File 2 tra parentesi quadre. Ad esempio se entrambi i file hanno una colonna importo, quella di F2 diventa importo [nome_file2]. Un avviso giallo segnala le colonne rinominate prima di procedere.

5. Lista dei Campi con Badge F1 / F2 / 🔗

Dopo l'unione, la lista dei campi disponibili mostra tutti i campi di entrambi i file in un unico elenco. Ogni campo porta un piccolo badge colorato che ne indica l'origine:

  • F1 — il campo proviene dal File 1.
  • F2 — il campo proviene dal File 2.
  • 🔗 — il campo è stato usato come chiave di join (proviene da F1 ma rappresenta la corrispondenza tra i due file).

I badge sono puramente informativi: tutti i campi si usano allo stesso modo, trascinandoli nelle aree RIGHE, COLONNE e VALORI.

6. Costruzione Report

  • ☰ RIGHE (Gerarchia): Trascina qui i campi per raggruppare i dati in modo gerarchico. L'ordine conta: il primo campo è il livello più alto (es. CDC → Impegno → Determina).
  • ⬌ COLONNE (Opzionale): Trascina qui un campo per "pivotare" i dati in orizzontale, creando una colonna per ogni valore distinto (es. Mesi, Anni, Categorie).
  • ∑ VALORI (Dati): Trascina qui i campi numerici da aggregare. Puoi scegliere la funzione: sum (somma), count (conteggio), avg (media), min, max.
  • Usa la barra di ricerca nella lista Disponibili per trovare rapidamente un campo.
  • Il bottone 🔗 Unisci permette di combinare più campi testuali in uno solo selezionando le checkbox (es. unire "Nome" e "Cognome").
  • Il bottone 🧹 Svuota rimuove tutti i campi dalle tre aree, riportando tutto alla lista Disponibili.

7. Opzioni Campi (I Flag)

Ogni campo trascinato in RIGHE mostra una serie di controlli:

  • A-Z / Z-A Ordinamento crescente o decrescente per quel livello.
  • V Vuoto se duplicato: nasconde il testo quando il valore è uguale alla riga precedente, rendendo il report più leggibile.
  • E Espandi: mostra tutte le righe di dettaglio; se disattivo mostra solo la riga di sintesi del gruppo.
  • S Subtotale: aggiunge una riga di totale parziale alla fine di ogni gruppo.
  • C Compatta: mette il campo nella stessa colonna del livello superiore. Non disponibile sul primo livello.
  • B Grassetto: visualizza i valori in grassetto.

I campi in VALORI hanno il flag % che mostra il dato come percentuale sul totale colonna.

8. Barra degli Strumenti (Anteprima)

  • Colori / Box: attiva o disattiva lo stile grafico e il tema cromatico.
  • RIGA — Totale: aggiunge una colonna finale con la somma dei valori di riga.
  • RIGA — % Incidenza: aggiunge il peso percentuale di ogni riga sul totale generale.
  • Tot. Gen.: aggiunge la riga finale con il totale complessivo.
  • Nascondi Vuote: nasconde le colonne il cui totale è zero o vuoto.
  • NUMERI — Dec: imposta il numero di decimali (0–4).
  • NUMERI — 1.000: attiva il separatore delle migliaia.
  • NUMERI — €: aggiunge il simbolo euro.

9. Copia Tabella negli Appunti 📋

Il bottone 📋 Copia Tabella copia la tabella in due formati simultaneamente:

  • HTML formattato → in Word o Outlook mantiene colori, bordi e grassetti.
  • Testo tabulato (TSV) → in Excel o Google Sheets distribuisce i dati nelle celle corrette.

10. Annulla / Ripeti (Undo/Redo)

I pulsanti ↩ e ↪ (o Ctrl+Z / Ctrl+Y) annullano o ripetono le modifiche alla struttura del report. Lo storico mantiene fino a 40 stati.

11. Salva e Carica Modello

  • 💾 Salva (o Ctrl+S): salva la configurazione in un file .json.
  • 📂 Carica: ricarica una configurazione salvata. Se il CSV contiene gli stessi campi, il report viene ricostruito automaticamente.

12. Export Finale

  • 📥 Scarica Excel: genera un file .xlsx con intestazioni colorate, subtotali con formule SUBTOTAL, formattazione numerica e larghezze ottimizzate.
  • 📄 Scarica PDF: genera un .pdf in formato landscape. Ideale per stampa o invio.
  • Puoi modificare il nome del file prima di scaricare. Usa Ctrl+Invio per passare allo step successivo senza mouse.
